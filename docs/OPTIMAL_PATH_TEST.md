# Тест выбора короткого маршрута JAKA

В первом терминале запустите обычный MoveIt для робота:

```bash
./run_real.sh 10.5.5.100
```

Остановите ручное движение робота. Во втором терминале, из папки проекта:

```bash
./run_optimal_test.sh --face z_plus
```

Команда только рассчитывает и показывает выбранную траекторию в RViz.
Исполнение в тестовом запуске отключено, включая передачу `--mode execute`.
Он использует текущую сцену MoveIt и текущие суставы робота; объекты сам не добавляет.
В обычном запуске стартовый куб присутствует. Для другой детали передайте её ID
через `--object`, а нужную грань или ребро — через `--face` или `--edge`.

Для короткого теста одного участка:

```bash
./run_optimal_test.sh --face z_plus --begin 0.0 --end 0.25 --max-candidates 8 --search-seconds 120
```

По умолчанию сравниваются до 12 кандидатов с ориентировочным бюджетом 180 секунд.
Время проверяется между кандидатами: уже начатый расчёт полного маршрута завершается.
Каждый вариант включает подход, выбранный проход и подъём TCP на 25 см с прежней
ориентацией. Неполные и столкновительные варианты исключаются штатными проверками
MoveIt. Проверки полной модели насадки и ограничений скорости сохраняются.

Сначала проверяется исходная ориентация, затем поворот вокруг оси TCP, близкий
к текущей ориентации, соседние повороты и различные начальные решения IK.
Заданные наклон и направление наклона не изменяются. `--orientation-mode fixed`
запрещает также подбор поворота вокруг TCP; остаётся сравнение решений суставов.
Эквивалентные углы IK выбираются ближе к текущим суставам в пределах ограничений
модели, затем путь к ним заново проверяется планировщиком столкновений.

Критерий: сумма фактических перемещений суставов с весами
1.2 / 1.2 / 1.2 / 1.5 / 2 / 2.5, плюс 0.5 максимального отклонения сустава
от начала и 0.01 длительности в секундах. Полные обороты не сворачиваются
по модулю 360°. Запястье получает больший вес, чтобы уменьшить лишние развороты.
Это лучший вариант среди проверенных кандидатов, а не гарантия глобального оптимума.

Результаты сохраняются в `diagnostics/optimal_test/*.json`: все попытки и причины
отказов, стоимость выбранного маршрута, улучшение относительно первого допустимого
варианта и полная выбранная траектория. В RViz публикуется только итоговый вариант.
Если робот или препятствия изменились во время сравнения, итоговый план отклоняется.

Обычные `run_real.sh`, панель и `weld.sh` продолжают использовать прежний алгоритм.
Тестовый режим запускается только отдельным `run_optimal_test.sh`.
