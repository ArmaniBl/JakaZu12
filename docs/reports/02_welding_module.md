# Отчёт № 2. Разработка модуля имитации сварки

**Дата:** 5 ноября 2026 года.  
**Этап:** определение зоны сварки и движение end-effector по выбранному контуру.

## Цель

Реализовать модуль, который по известной геометрии объекта определяет доступные
геометрические грани и рёбра, позволяет выбрать часть объекта и организует
имитацию сварочного прохода. По уточнению пользователя основным режимом выбран
контур одной грани. Дополнительно сохранён режим отдельного ребра.

Первичные испытания проведены на заготовке 300 × 300 × 200 мм с центром
(−1; 0; 0,1) м относительно `world`.

## Реализованные компоненты

| Компонент | Назначение |
| --- | --- |
| `welding_sim/geometry.py` | Геометрия BOX: рёбра, контуры, преобразования, дискретизация пути |
| `welding_sim/runner.py` | Получение объекта из MoveIt, визуализация, планирование и исполнение |
| `scripts/weld.py` | Точка запуска ROS-процесса |
| `weld.sh` | Подключение окружения и запуск модуля из WSL |
| `test/test_welding.py` | Автоматические проверки геометрии и ограничений |

Компоненты входят в пакет `ur10_isaac_moveit_config` и устанавливаются при сборке.

## Алгоритм работы

### Получение геометрии

Модуль запрашивает объект `welding_workpiece` через `/get_planning_scene`.
Поддержан объект из одного примитива BOX в системе `world`.
Учитываются размеры, поворот и композиция позы объекта с позой примитива.
Координаты путей вычисляются из полученной модели, а не задаются отдельно
для каждого ребра куба.

Для BOX определяются шесть граней, двенадцать рёбер и восемь вершин.
Грани именуются по локальным осям объекта: `x_plus`, `x_minus`, `y_plus`,
`y_minus`, `z_plus`, `z_minus`. Имя ребра образуется из двух смежных граней,
например `x_plus__z_plus`.

### Выбор зоны

Пользователь может выбрать полный контур грани, участок этого контура,
одно ребро или участок ребра. Начало и конец задаются долями длины от 0 до 1.
В режиме грани эти доли относятся ко всему периметру.

Для верхней грани тестового объекта периметр равен 1,2 м.
Диапазон 0,2–0,8 соответствует участку длиной 0,72 м.
В режиме ребра длиной 0,3 м тот же диапазон соответствует 0,18 м.

### Построение прохода

Контур грани представляет непрерывный прямоугольный обход. Углы включаются
в последовательность точек явно, чтобы геометрический генератор не соединял
стороны диагоналями. Полный контур замкнут; выбранный неполный участок открыт.

Для грани инструмент ориентируется осью +Z к поверхности и сохраняет ориентацию
на всём обходе. Путь `tool0` смещается от поверхности по внешней нормали.
В режиме ребра используется внешняя биссектриса нормалей смежных граней.

Основные значения по умолчанию:

| Параметр | Значение |
| --- | --- |
| Отступ инструмента | 0,03 м |
| Дополнительный подвод/отвод | 0,05 м |
| Шаг дискретизации | 0,005 м |
| Скорость рабочего прохода | 0,02 м/с |
| Коэффициент скоростей и ускорений суставов | 0,05 |
| Поворот инструмента вокруг Z | 0° |

Для предварительного просмотра публикуются маркеры `/welding/markers`.
В RViz отображаются рёбра, выбранная зона и смещённый путь инструмента.

### Планирование и выполнение

Рабочий маршрут состоит из подвода, прохода и отвода.
Сначала проверяется весь маршрут, затем разрешается исполнение.
Для подвода используются IK и планирование MoveIt; для прохода —
`/compute_cartesian_path` с проверкой коллизий и ограничением суставных скачков.

Реализован перебор начальных приближений IK: достижимость стартовой точки
не считается достаточным условием достижимости всего контура.
Частичный декартов путь отклоняется. После подвода рабочая часть пересчитывается
по фактическим состояниям суставов; допуск начальной позы MoveIt не увеличивается.

Дополнительно по FK проверяется скорость между соседними точками готового пути.
Если необходимо, время растягивается, а скорости и ускорения согласованно уменьшаются.
Это ограничение дискретной плановой траектории, а не измерение фактической
непрерывной скорости end-effector.

Исполнение выполняется через `/execute_trajectory`. Предусмотрены проверка
наличия издателя Isaac, обнаружение изменения заготовки, тайм-аут и запрос отмены
активного action при прерывании процесса.

## Проверки и выявленные особенности

Восемь автоматических тестов подтвердили:

- топологию BOX и координаты вершин;
- выбор рёбер, длины участков и отступы;
- композицию поворота и смещения объекта;
- отказ на некорректных параметрах;
- отказ на частичном декартовом пути;
- замкнутость полного контура и прохождение углов;
- длину выбранной части периметра;
- согласованное изменение времени, скоростей и ускорений.

Практические испытания показали, что при отступе 0,10 м полный верхний контур
не всегда достижим. Для проверки выбран отступ 0,03 м. Кроме того, реальная
обратная связь после подвода могла расходиться с расчётной стартовой позой
следующего сегмента больше допуска 0,01 рад. Это устранено пересчётом рабочего
прохода из фактической позы.

После отвода положение `tool0`, вычисленное по обратной связи суставов,
составило приблизительно (−0,84998; −0,15002; 0,28002) м при целевом положении
(−0,85; −0,15; 0,28) м. Эти данные подтверждают конечное положение в кинематической
модели, но не являются независимым измерением положения инструмента в USD-сцене.

## Ограничения и состояние этапа

Модуль пригоден для начальной имитации прохода по известному BOX-объекту.
Распознавание поверхности по камере, произвольные меши, модель горелки,
калиброванный TCP и физика сварки не реализованы.

Полный проход проверен для одной верхней грани. Досягаемость остальных граней
и точность слежения по всем промежуточным точкам отдельно не подтверждены.
Нижняя грань потребует учёта опоры, если она будет добавлена в сцену.

Режимы запуска и параметры описаны в [WELDING.md](../WELDING.md).
