## Общий результат

Создана цепочка от выбора зоны на известной геометрии до исполнения прохода
end-effector в Isaac Sim. Пользователь может работать через командную строку
или локальную веб-панель. Управление и планирование выполняются в WSL2 Ubuntu 24.04,
Isaac Sim работает на Windows 11.

Для испытаний используется BOX-заготовка размером **300 × 300 × 200 мм** с центром
**X = −1 м, Y = 0 м, Z = 0,1 м** относительно `world`. Заготовка добавляется
в сцену планирования MoveIt и отображается в RViz.

Рабочие результаты подтверждены журналами и JSON-отчётами предыдущих проверок.
При подготовке этих документов повторное движение робота и повторный прогон тестов
не выполнялись.

## Границы выполненных работ

- Реализована имитация движения инструмента. Сварочная дуга, нагрев, контакт
  и формирование шва не моделируются.
- Геометрия определяется из объекта BOX в MoveIt, а не по изображению камеры
  или облаку точек.
- USD-объект заготовки в Isaac Sim автоматически не создаётся.
- Используется модель UR10. Перенос траекторий на физический JAKA ZU12,
  калибровка его базы и TCP в выполненные проверки не входили.
- При завершении `move_group` остаётся известный segfault MoveIt 2.12.4;
  работа планирования и исполнения проверена отдельно от этого сбоя завершения.
- Исполнение полного контура проверено через модуль командной строки.
  В веб-тесте команда исполнения перехватывалась до передачи в ROS.

Изменения находятся в рабочей копии ветки `welding`. Коммит и отправка изменений
в удалённый репозиторий в рамках описанных работ не выполнялись.

Приоритетные направления развития: устранение сбоя завершения MoveIt,
создание согласованной USD-заготовки, добавление модели горелки и TCP,
